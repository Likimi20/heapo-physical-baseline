3. BALANCE TEMPERATURE - COMPUTED FROM PHYSICS, NEVER FITTED
==============================================================================
  T_bal = 20 - q_int * A / H_tot , internal gains only.
  Solar is NOT included: the supplied 15-25 kWh/m2a is an ANNUAL figure
  and solar is lowest exactly when heating is needed. Using an annual mean
  would overstate winter gains. DECLARED GAP.

  T_bal by era (q_int = 5.0 W/m2):
    < 1975       n=49   median 18.4 C   range 18.4 - 18.4
    1976 - 80    n=30   median 17.2 C   range 17.2 - 17.2
    1981 - 85    n=29   median 17.2 C   range 17.2 - 17.2
    1986 - 90    n=13   median 17.2 C   range 17.2 - 17.2
    1991 - 95    n=15   median 16.4 C   range 16.4 - 16.4

    2000 - 10    n=39   median 15.2 C   range 15.2 - 15.2
    > 2010       n=21   median 13.9 C   range 13.9 - 13.9

  FINDING: the balance temperature is NOT a fleet constant. It moves with
  the envelope, by design - a leaky house needs heating at a higher outdoor
  temperature than a tight one. A single fleet-wide base is wrong for both
  ends, and this is invisible to any model that fixes the base.
